How it works

Listing form: Anyone can fill it in. On submit, the login modal opens if they're logged out, and their answers send automatically after sign-in. The server checks the session cookie too. Submissions go into a pending table, not onto the site. There's no admin screen yet, so you review them in TablePlus and set status to approved.
Profiles: One layout serves everyone at impactmaker.html?slug=..., with no per-person files. It shows photo, SDG, name and bio, then optional stats, a contributions timeline, skills and links.
Missing details: I did not invent any biographies. Only name and SDG are filled in for the nine people. Sections with no data are hidden, and contributions shows "coming soon". The full record shape is in the note at the bottom of data/impactmakers.js.


To see the complete design, paste this into one person's record:

role: "Programme Lead", location: "Akure, Ondo", since: 2024,
bio: "A short bio in their own words.",
stats: { projects: 6, hours: 420, communities: 3 },
contributions: [{ year: 2026, title: "Example contribution", description: "What they did and the result." }],
skills: ["Community organising"],
